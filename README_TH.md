# Rider Frontend (Angular 22 + Tailwind 4)

```bash
cd frontend
npm install
npm start          # http://localhost:4200
```

เปลี่ยนที่อยู่ API ได้ที่ `src/app/core/api.config.ts` (ค่าเริ่มต้นคือ https://rider-api-4gww.onrender.com)

| เส้นทาง | หน้า |
|---|---|
| `/` | ภาพรวม (สถานะเซิร์ฟเวอร์, จำนวนออเดอร์, ทางลัด) |
| `/customers` | ลูกค้า: ค้นหาชื่อ, ค้นใกล้เคียง 1 กม., เพิ่ม/แก้ไข/ลบ |
| `/orders` | ออเดอร์: กรองสถานะ, ค้นใกล้เคียง 2 กม., เพิ่ม/แก้ไข/ลบ, จำลอง 20–30, ล้างทั้งหมด |
| `/planner` | จัดเส้นทาง: คำนวณ → ดูแผนผัง/ต้นทุน/กำไร → บันทึกมอบหมายงาน |
| `/routes` | รายการเส้นทางที่บันทึก |
| `/routes/:id` | รายละเอียดเส้นทาง + แผนผังจุดส่ง |
| `/rider` | หน้ามือถือไรเดอร์: ใส่รหัสเข้าดูงาน, โทร/แผนที่, กดส่งเสร็จ |
